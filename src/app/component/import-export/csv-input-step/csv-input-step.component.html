Estructura esperada del CSV

Copia el siguiente formato para dárselo a una IA o usarlo como plantilla en Excel. El orden de las columnas es estricto.

titulo,monto,categoriaNum,tipo,tipomonto,cuotas,cuotasPagadas,fecha,estado Desayuno,50,1,U,,,,2024-01-01,P Internet,300,2,R,,,,2024-01-01,P Celular,1200,3,C,T,12,2,2024-01-01,
  • tipo: U (Único), C (Cuota), R (Recurrente).
  • tipomonto: Solo para Cuotas (M = Mensual, T = Total).
  • fecha: Formato YYYY-MM-DD.
  • estado: P (Pagado), N (Pendiente). Vacío en cuotas.
